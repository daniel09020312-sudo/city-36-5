# 36.5 — 이상사회 3D 투어

과열되거나 식어도 다시 36.5로 돌아오는 도시. Vite + Three.js로 만든 14장면 투어입니다. 고층 빌딩, 아파트 단지, 공원, 가로수, 도로와 자동차가 있는 현대 도시를 배경으로, 장면마다 설명, 예시, 관련 기사를 붙였습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 을 엽니다.

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | `dist/` 에 배포용 파일 생성 |
| `npm run preview` | 빌드 결과 미리 보기 |
| `npm test` | 화면에 나오는 숫자(의혹 77명 중 1명 등) 검증 |

## 조작

- **투어**: [이전]·[다음] 버튼, `←` `→` 키. 주소 끝의 `#s0`~`#s13` 으로 장면을 바로 엽니다.
- **자유 탐험**: 오른쪽 위에서 전환하거나 `F` 키. 끌어서 돌리고, 지구 이름표를 누르면 그 장소로 갑니다.

## 글과 색을 고칠 때

코드를 몰라도 아래 두 파일만 고치면 됩니다.

- `src/content/scenes.js` — 장면 14개의 제목, 설명, 예시, "이 장소가 뜻하는 것", 관련 기사(제목·언론사·날짜·링크), 버튼 문구, 카메라 위치
- `src/config/palette.js` — 색 (앰버 `#F5A25D` · 레드 `#E5484D` · 블루 `#6E9BD6` 과 무채색)

| 번호 | 장소 | 뜻하는 것 |

## 폴더

```
src/
  main.js               렌더러, 루프
  styles.css            화면 위 글자와 조작부
  config/palette.js     색
  config/layout.js      지구와 장소의 위치
  content/scenes.js     글과 카메라
  core/                 투어, 온기 셰이더, bloom, 입자, 빛줄기, 라벨
  world/                대지, 건물(오피스·아파트 단지), 공원·가로수·도로·자동차, 시민 1,000명
  districts/            광장·회복·조절·존엄 지구와 한계·엔딩의 장치와 동작
  math/                 화면 숫자를 내는 계산
  ui/overlay.js         설명 패널과 슬라이더·버튼
tests/math.test.js      계산 검증
```

## 화면 규칙

- 도시는 무채색으로 짓고, 색은 상태를 뜻할 때만 씁니다. 앰버는 균형, 레드는 과열, 블루는 식음·기계 판정입니다.
- 색은 장면의 초점에서 번져 나옵니다.
- 빛나는 것은 색이 있는 것뿐입니다.
- 엔딩에서는 건물은 회색 그대로 두고 시민만 앰버가 됩니다.

## GitHub Pages 배포

`vite.config.js` 의 `base` 가 `'./'` 라서 저장소 이름과 상관없이 열립니다.
저장소에 올린 뒤 Settings → Pages → Source 를 **GitHub Actions** 로 바꾸면 `.github/workflows/deploy.yml` 이 `main` 에 올릴 때마다 배포합니다.

# 36.5 — 이상사회 3D 투어

후마니타스 '이상 사회 만들기 프로젝트'의 이상사회 **36.5**를 3D 도시로 보여 주는 한 페이지 웹사이트입니다. 36.5는 사람의 체온이고, 흔들려도 다시 균형으로 돌아오는 사회를 뜻합니다. 기준 문서는 상위 폴더의 `SPEC.md`입니다.

주소: https://daniel09020312-sudo.github.io/city-36-5/

## 실행

```bash
npm install
npm run dev
```

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | `dist/` 에 배포용 파일 생성 |
| `npm run preview` | 빌드 결과 미리 보기 |
| `npm test` | 화면에 나오는 숫자(의혹 77명 중 1명 등) 검증 |

## 조작

- **투어**: [이전]·[다음] 버튼, `←` `→` 키. 주소 끝의 `#1`~`#8`로 장면을 바로 엽니다.
- **자유 탐험**: 오른쪽 위에서 전환하거나 `F` 키. 끌어서 돌리고, 구역 이름표를 누르면 그 장면으로 갑니다.
- **걷기**: 오른쪽 위에서 전환. 시민의 눈높이로 거리를 걷습니다. `W A S D`나 방향키로 걷고(`Shift`는 빨리), 화면을 끌어 둘러봅니다. `Esc`로 나갑니다. 휴대폰에서는 왼쪽 아래를 밀어 걷고 오른쪽을 끌어 둘러봅니다.

## 글과 색을 고칠 때

코드를 몰라도 아래 두 파일만 고치면 됩니다.

- `src/scenes.js` — 8장면의 제목, 글, 예시, "이 장소가 뜻하는 것", 관련 기사(제목·언론사·날짜·링크), 버튼 문구, 카메라 위치
- `src/palette.js` — 색 (주황 `#F5A25D` · 빨강 `#E5484D` · 파랑 `#6E9BD6` 과 회색)

## 폴더

```
src/
  main.js               렌더러, 화면 루프
  scenes.js             8장면의 글과 카메라 (한국어 글은 여기에만)
  palette.js            색 값
  styles.css            화면 위 글자와 조작부
  config/layout.js      구역과 장소의 위치
  core/                 투어(tour.js), 걷기(walk.js), 색 번짐, bloom, 입자, 빛줄기, 라벨
  world/                바닥, 건물(오피스·아파트 단지), 공원·가로수·도로·자동차, 시민 1,000명
  districts/            광장·회복·조절·존엄 구역과 마지막 장면의 장치와 동작
  math/                 판정 시뮬레이션(ppv.js), 도시 온도(thermo.js)
  ui/                   글 패널·슬라이더·버튼(overlay.js), 로딩 화면(loader.js)
tests/math.test.js      계산 검증
```

## 화면 규칙

- 도시는 회색으로 두고, 지금 설명하는 부분에만 색을 입힌다. 주황은 균형·회복, 빨강은 비난·의혹, 파랑은 AI 판독·예측이다.
- 특정 병명이나 구체적인 의료 수치는 화면에 쓰지 않는다.
- 마지막 장면에서는 건물은 회색 그대로 두고 시민만 주황이 된다.
